## Requisitos

### Funcionais

| Épico | Requisitos | Descrição | Priorização |
|-------|------------|-----------|-------------|
| EP01 | RF01 | Eu enquanto, usuário, desejo traduzir discursos bidirecionalmente entre dois idiomas para compreender seu significado | must |
| EP01 | RF02 | Eu enquanto, usuário, desejo escutar a pronúncia da tradução de um discurso para eu conseguir falar uma nova língua com mais facilidade | should |
| EP01 | RF03 | Eu enquanto, usuário, desejo poder falar um discurso no idioma a ser traduzido e receber a sua tradução em um idioma diferente para conseguir uma tradução mesmo não conseguindo escrever | could |
| EP01 | RF04 | Eu enquanto, usuário, desejo ver a foto ao traduzir um discurso para poder lembrar com mais facilidade daquele discurso | should |
| EP01 | RF05 | Eu enquanto, usuário, no modo criança, desejo uma animação ao pedir a tradução de uma frase | wont |
| EP01 | RF06 | Eu enquanto, usuário, desejo compartilhar a tradução do discurso o qual pesquisei | wont |
| EP01 | RF07 | Eu enquanto, usuário, desejo compartilhar eventos/pesquisas relacionadas aos Munduruku | wont |
| EP01 | RF08 | Eu enquanto, usuário, quero poder ajustar o tamanho da fonte do aplicativo | could |
| EP02 | RF09 | Eu enquanto, usuário, desejo favoritar traduções pesquisadas | should |
| EP02 | RF10 | Eu enquanto, usuário, desejo ver histórico das últimas palavras pesquisadas | could |
| EP02 | RF11 | Eu enquanto, usuário, desejo buscar por discursos nas traduções favoritas | could |
| EP02 | RF12 | Eu enquanto, usuário, desejo excluir traduções do meu histórico | should |
| EP02 | RF13 | Eu enquanto, usuário, desejo excluir traduções das minhas traduções favoritas | should |
| EP03 | RF14 | Eu enquanto, professor, desejo adicionar tradução de um discurso para abastecer as possíveis traduções do aplicativo | must |
| EP03 | RF15 | Eu enquanto, professor, preciso marcar se a tradução é apenas para adultos | must |
| EP03 | RF16 | Eu enquanto, professor, quero ver uma lista das traduções que eu adicionei no aplicativo | must |
| EP03 | RF17 | Eu enquanto, professor, quero gerenciar uma tradução que eu adicionei para poder fazer uma melhoria ou correção | must |
| EP04 | RF18 | Eu enquanto, usuário, desejo curtir postagens | wont |
| EP04 | RF19 | Eu enquanto, usuário, desejo comentar em postagens | wont |
| EP04 | RF20 | Eu enquanto, usuário, desejo denunciar postagens inapropriadas | wont |
| EP04 | RF21 | Eu enquanto, usuário, desejo adicionar imagens a postagens | wont |
| EP04 | RF22 | Eu enquanto, administrador, desejo poder gerenciar (ver, editar, adicionar e apagar) as categorias de publicações para poder atualizar de acordo com as necessidades da rede social | wont |
| EP04 | RF23 | Eu enquanto, moderador, desejo poder apagar alguma publicação que eu considerar inapropriada | wont |
| EP05 | RF24 | Eu enquanto, usuário, desejo enviar sugestões aos desenvolvedores | could |
| EP05 | RF25 | Eu enquanto, usuário, desejo reportar erros | could |
| EP05 | RF26 | Eu enquanto, usuário, desejo acessar manual do aplicativo | should |
| EP05 | RF27 | Eu enquanto, usuário, desejo encontrar informações sobre os Munduruku | must |
| EP05 | RF28 | Eu enquanto, usuário, desejo acessar a política de privacidade | must |
| EP06 | RF29 | Eu enquanto, usuário, desejo poder criar uma conta nova com meus dados pessoais | must |
| EP06 | RF30 | Eu enquanto, usuário, desejo acessar minha conta via e-mail e senha | must |
| EP06 | RF31 | Eu enquanto, usuário, desejo recuperar minha senha via email | could |
| EP06 | RF32 | Eu enquanto, usuário, desejo poder editar informações do meu perfil | should |
| EP06 | RF33 | Eu enquanto, usuário, desejo poder sair da conta para poder me conectar com outro perfil | must |
| EP06 | RF34 | Eu enquanto, usuário, ao me cadastrar devo entrar no modo criança caso tenha menos de 16 anos | must |
| EP07 | RF35 | Eu enquanto, administrador, desejo poder ver uma lista com os usuários e seus respectivos níveis no aplicativo | must |
| EP07 | RF36 | Eu enquanto, administrador, desejo poder editar o nível dos usuários no aplicativo | must |
| EP07 | RF37 | Eu enquanto, administrador, desejo poder buscar por nome um usuário para encontrá-lo com mais facilidade | could |
| EP07 | RF38 | Eu enquanto, administrador, quero editar o nível de um usuário para banido para que este perfil não possa mais voltar a usar o aplicativo | wont |
| EP07 | RF39 | Eu enquanto, administrador, quero gerenciar os idiomas disponíveis para tradução | wont |
| EP08 | RF40 | Eu enquanto, moderador, desejo poder ver uma lista com o título dos reportes dos usuários, data e hora de criação para poder tomar ações e melhorar o aplicativo | should |
| EP08 | RF41 | Eu enquanto, moderador, desejo poder alterar a ordem da lista de reportes e ver os mais recentes ou os mais antigos primeiro para poder dar prioridade aos reportes mais significativos | could |
| EP08 | RF42 | Eu enquanto, moderador, desejo poder filtrar a lista de reportes para poder ver apenas erros, denúncias ou sugestões podendo ser simultaneamente mais de um | could |
| EP08 | RF43 | Eu enquanto, moderador, desejo poder ver com mais detalhe algum reporte para ver melhor a descrição e se houver a imagem | should |
| EP08 | RF44 | Eu enquanto, moderador, desejo poder marcar os reportes como lidos para me organizar quanto às necessidades do aplicativo | could |
| EP08 | RF45 | Eu enquanto, moderador, desejo alterar o status dos reportes para recusado ou realizado para poder me organizar quanto às ações necessárias | could |
| EP08 | RF46 | Eu enquanto, moderador, ao entrar na página de moderação desejo ver apenas aqueles sem status para poder me deparar inicialmente apenas com o que ainda precisa de alguma ação | could |
| EP08 | RF47 | Eu enquanto, moderador, desejo poder filtrar os status para poder ver também os reportes recusados ou realizados podendo ser mais de um simultaneamente | could |
| EP08 | RF48 | Eu enquanto, moderador, desejo poder apagar alguma tradução que eu considerar não condizente | must |
| EP08 | RF49 | Eu enquanto, moderador, desejo poder ver as traduções que existem no aplicativo | must |
| EP08 | RF50 | Eu enquanto, moderador, desejo poder buscar as traduções que existem no aplicativo pelo idioma e/ou discurso | could |
| EP08 | RF51 | Eu enquanto, moderador, desejo poder bloquear ou desbloquear uma tradução para crianças com o objetivo de poder corrigir o bloqueio ou desbloqueio incorreto da tradução | could |
| EP08 | RF52 | Eu enquanto, usuário, desejo denunciar uma tradução incorreta | could |
| EP08 | RF53 | Eu enquanto, usuário, quero entrar em contato com a equipe de desenvolvimento para me candidatar a ser professor do aplicativo para poder contribuir com as traduções | wont |
